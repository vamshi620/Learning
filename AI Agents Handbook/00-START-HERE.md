## 🗺️ Learning Paths

### Path A — I Want to Understand Gen AI & RAG
```text
01 → 02 → 03 → (04 or 05)
```
Focuses on understanding how large language models work, what embeddings are, and how to build a ChatGPT-like app over your own company data using RAG.

### Path B — I Want to Build AI Agents
```text
01 → 03 → 08 → 09 → 10
```
Focuses on "Agentic AI"—where the AI has access to tools (like searching the web, querying a database, or calling APIs) and makes autonomous decisions.

### Path C — I Want to Master GitHub Copilot
```text
06 → 07
```
Focuses on becoming a power user of GitHub Copilot and extending its functionality by writing your own Custom Copilot Agents using Python.
